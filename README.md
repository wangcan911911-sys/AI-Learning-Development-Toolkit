# AI Learning & Development Toolkit

A practical open-source resource library for Learning & Development professionals, Training Managers, HR Business Partners and Talent Development teams.

## Project Overview

This repository provides practical templates, AI prompts, learning roadmaps and interview resources to help organizations improve learning effectiveness and talent development.
